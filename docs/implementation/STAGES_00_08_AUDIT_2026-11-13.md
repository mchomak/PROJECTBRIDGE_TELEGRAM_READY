## Найденные и исправленные ошибки

1. **Данные паспорта при отправке анкеты.** Если в поле паспорта или промежуточном узле JSON уже находилось непустое значение, не являющееся объектом, запись вложенного значения анкеты могла заменить его объектом. Теперь операция возвращает понятный ответ 409 с просьбой проверить паспорт исполнителю; транзакция откатывается, исходные данные и черновик сохраняются. Добавлены проверки на уровне сервиса и API.
2. **Позиция этапа Project State.** Чрезмерно большое положительное число проходило проверку и не помещалось в тип PostgreSQL. Теперь создание и изменение отклоняют значения выше 2 147 483 647 с ответом 400. Добавлен API-тест для обеих операций.
3. **Состояние чата.** При переключении проектов локальное состояние чата могло сохраняться; совпадения идентификаторов сообщений разных отправителей могли неверно связывать сообщения; подтверждение доставки через историю или WebSocket и ошибка параллельного REST-запроса могли приводить к неверному состоянию или очистке черновика. Состояние изолировано по проекту, сообщения сопоставляются с учётом отправителя, подтверждённые сообщения считаются доставленными, а черновик очищается только для соответствующей версии. Добавлены проверки интерфейса.

## Принятые решения по документации

**Токен приглашения.** Бриф этапа 04 требовал возвращать исходный токен при создании; API-контракт и правила безопасности запрещали включать его в ответ API и разрешали передавать только в письме. Выбрано второе: токен создаётся при создании приглашения и передаётся в ссылке письма, в API не возвращается, в базе хранится его хеш. Бриф этапа 04 приведён в соответствие. Это уменьшает число мест, где может оказаться секретная ссылка, и соответствует действующей реализации и правилам безопасности.

**Конфликт структуры паспорта.** Существующее непустое значение на пути отображения анкеты не заменяется автоматически. Операция останавливается с объяснимым конфликтом и сохраняет данные: исполнитель может проверить паспорт до повторной попытки. Такое решение сохраняет инвариант о недопустимости молчаливого перезаписывания данных.
