# Как читать эту папку

- `dashboard.html` — панель прогресса сборки; она обновляется из `state.js`.
- `index.html` — тот же файл для короткого адреса `/`.
- `<дата>-<проект>--wip/` — текущая сборка. После приёмки суффикс `--wip` снимается.
- Внутри папки сборки: brief — исходная задача, `manifest.md` — требования и их статус, `spec.md` — спецификация, `tickets/` — таски.

Если сборка прервалась, состояние находится в `.autopilot/state.js`; после приёмки оно архивируется как `state.js` в папке прогона.
