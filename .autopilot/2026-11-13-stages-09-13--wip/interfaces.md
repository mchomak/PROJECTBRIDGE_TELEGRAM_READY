# Границы

Доменные приложения владеют собственными данными; AI Router — единая граница вызовов моделей; Project State изменяется через свои сервисы. Подробности — в технических документах и брифах.

Начальное пространство эмбеддингов: `text-embedding-3-small`, 1536 измерений; договорённый интерфейс этапа 09 — `apps.ai_assistant.embedding.embed_texts(texts, *, task_key="document_embedding") -> EmbeddingBatch(vectors, profile_key, model_name, profile_version)`, этап 10 подключает его к маршрутизатору.

Этап 10: `apps.ai_assistant.router` предоставляет генерацию, эмбеддинги и reranking по task key; профиль хранится в БД и управляется через Django Admin. Резервы затрат накапливаются по попыткам под общей блокировкой задачи, данные о расходе сохраняются при ошибках ответа. Для смены векторного пространства используется `reindex_document_embeddings`; обработка документов использует пакеты и защиту от устаревших задач.

Этап 11: ручной асинхронный анализ хранит приватные запросы и предложения; источники перепроверяются при применении, запись в Project State выполняется через сервис владельца в транзакции. Доступ ограничен активным членством исполнителя и статусами проекта `draft`/`active`; интерфейс показывает историю и предложения исполнителю.
