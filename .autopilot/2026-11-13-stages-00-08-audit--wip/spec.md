# Спецификация проверки

Сверить критерии этапов 00–08, документы и реализацию, включая роли, изоляцию проектов, ошибки и ограничения. Подтверждённые ошибки исправить с регрессионными тестами; спорные требования разрешать самостоятельно и согласовывать документы. Зафиксировать проверенные и непроверенные критерии, решения, изменения и результаты команд в Markdown-отчёте docs. Не затрагивать функциональность будущих этапов.

Решение: токен приглашения отправляется только по электронной почте; API его не возвращает, в базе хранится хеш.
