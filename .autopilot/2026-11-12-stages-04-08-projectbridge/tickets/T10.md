## Acceptance criteria

- [x] Archive requires both participants; rejection leaves the file active, and archived files leave the active list but remain restorable.
- [x] Restoring an archived file cancels any still-pending one-party deletion request atomically; an already approved deletion must be explicitly cancelled before restore.
- [x] Permanent deletion can be requested only from archived status and requires both approvals; the 30-day cancellation deadline begins at the second approval.
- [x] Either active project member can cancel before the deadline, returning the document to archived even if the parent project later closes; restore is a separate action with project-status and membership checks.
- [x] Celery Beat schedules an idempotent five-minute sweep that deletes expired source/Stage08 data, records minimal audit metadata, safely ignores cancelled/stale requests, and executes due approved requests regardless of later parent project status.
- [x] UI exposes both-party approval, rejection, restore, and cancellation deadline; tests cover consent, rejection, cancellation, eligibility, retries, data cleanup, and no cross-project access.
